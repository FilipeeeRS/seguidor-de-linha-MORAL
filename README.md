# Line follower

College project for my VCIOT class at PUC-Campinas. A small car in Webots follows a black line using its camera.

Made with Python, OpenCV and a PD controller.

## How to run

Install Webots R2025a and Python 3, then:

```
pip install opencv-python numpy
```

Open `worlds/carro.wbt` in Webots and press play.
